# 🌳 Forest Focus

**Forest Focus** is a productivity project that helps you stay focused using a simple and motivating idea:  
Every time you focus for a specific period, you grow a virtual tree 🌱 — and over time, your forest represents your real productivity and progress.

---

## 🎯 Project Idea
The goal of this project is to encourage users to stay focused through a gamified "virtual forest" concept.  
Each successful focus session plants a new tree, helping you visualize your consistency and achievements.

---

## ⚙️ Technologies Used
- **Laravel** – Backend framework  
- **MySQL** – Database  
- **Bootstrap / CSS / JavaScript** – Frontend  
- **Blade Templates** – For structured views  

---

## 🌱 Features
- Customizable focus timer  
- Track the number of trees planted and successful focus sessions  
- Daily or weekly productivity insights  
- Simple and interactive UI design

## 🚀 Run Locally

```bash
# Clone the project
git clone https://github.com/noor-20007/forest-focus.git

# Navigate to the project folder
cd forest-focus

# Install dependencies
composer install
npm install

# Create the environment file
cp .env.example .env

# Generate the app key
php artisan key:generate

# Start the development server
php artisan serve
